任务单元是什么

一个交易所 + 一个币种 + 一个数据类型 + 一个周期 + 一个缺失日

完整性检查按天拆分，所以同一个币种缺 3 天，就会产生 3 个任务单元。

OKX / BTCUSDT / klines / 5m / 2026-10-14

记录是什么
